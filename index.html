JKELTS LINK DISCOVERY
GitHub

Find the switch port behind a Windows network connection.

JKELTS LINK DISCOVERY helps technicians listen for LLDP and CDP advertisements so they can identify the connected switch, port ID, port description, platform, and VLAN details.

irm https://jkasalavia.github.io/jlink/r|iex

Requirement

Install Wireshark with TShark and Npcap for actual packet capture.

What It Helps With

Switch port lookup

Identify where a Windows endpoint is physically connected.

VLAN troubleshooting

Confirm advertised port or VLAN details where available.

Ticket documentation

Save discovered link data into a technician note.

Browsers cannot capture LLDP/CDP packets. This tool must run locally on Windows with Administrator rights and a packet capture driver such as Npcap.
